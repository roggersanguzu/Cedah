# Local fonts

These are the existing Google Fonts Latin variable subsets previously downloaded by Next.js for this project:

- **DM Sans**, weights 100–1000 (`dm-sans-latin.woff2`)
- **Manrope**, weights 200–800 (`manrope-latin.woff2`)

They are now served by `next/font/local` to preserve the design without build-time network requests. Each font's SIL Open Font License and copyright notice is included beside it, retrieved from the corresponding `ofl/dmsans` and `ofl/manrope` directories of the official [Google Fonts repository](https://github.com/google/fonts).
